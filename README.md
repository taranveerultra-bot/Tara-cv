# Taran — Digital Marketing & Development Portfolio

A premium personal portfolio for Taran, an independent New Zealand digital
marketing consultant and full stack developer.

## Positioning

Taran helps New Zealand businesses grow using SEO, AI, websites, automation
and digital marketing.

## Stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- Headless UI
- React Icons
- Vercel

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Portfolio content is maintained as typed data objects in `src/data`. Search for
`TODO:` before launch to find contact details, approved testimonials, project
links, screenshots and verified metrics that still need Taran's final content.

## Validation

```bash
npm run build
```

The project is connected to the `taranveerultra-bot/Tara-cv` GitHub repository
and deploys through Vercel.
